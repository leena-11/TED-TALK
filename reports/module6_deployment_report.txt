      ├── Page 2: Topic Explorer
      ├── Page 3: Model Benchmarks
      └── Page 4: About & Architecture

3.2 Recommendation Algorithm:

  Content-Based Mode:
    score(i) = cosine_similarity(seed_talk, talk_i)

  Hybrid Mode:
    score(i) = α × cosine_similarity(seed_talk, talk_i)
             + (1 - α) × normalized_log_views(talk_i)

  Where:
    α = Content weight (default 0.85, configurable 0.50–0.95)
    normalized_log_views = (log(1 + views) - min) / (max - min)

3.3 Data Flow:

  cleaned_ted_talks.csv (2,550 rows × 46 cols)
       ↓
  load_talks_data() → Pandas DataFrame with parsed tags
       ↓
  cosine_similarity.pkl (2,550 × 2,550 float32)
       ↓
  load_recommendation_models() → NumPy ndarray
       ↓
  get_recommendations() → Ranked list with explanations
       ↓
  Streamlit HTML Cards → User Interface
